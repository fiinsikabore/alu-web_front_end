# Responsive design

Making the **Techium** homepage responsive: the same page adapts to large screens, tablets and phones.

## Learning objectives

- Mobile-first design
- Media queries and breakpoints (992px, 767px, 480px)
- Flexible CSS units (`%`, `rem`, `vh`) and `max-width`
- Responsive vs adaptive design

## Files

| Files | Task |
|---|---|
| `00-index.html`, `00-styles.css` | Starter files |
| `01-index.html`, `01-styles.css` | 0. Fix the hero banner |
| `02-index.html`, `02-styles.css` | 1. Make the container flexible (`width` → `max-width`) |
| `02-1-index.html`, `02-1-styles.css` | 2. Fix layout issues with media queries (`max-width: 767px`) |
